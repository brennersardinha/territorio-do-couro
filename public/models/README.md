Coloque neste diretorio o arquivo `sapato-social.glb` para substituir o modelo procedural.

Objetos recomendados no arquivo:
- solado
- palmilha
- cabedal
- lingueta
- calcanhar
- cadarco
- cola
- caixa ou caixa_sapatos

O carregador procura esses nomes sem diferenciar maiusculas e minusculas. Se o arquivo nao existir ou estiver incompleto, a aplicacao continua usando o modelo procedural.
